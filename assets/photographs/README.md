# Original physical book photographs

Seventeen photographs supplied by the project author, converted from HEIC to JPEG for browser compatibility, resized without cropping, and stripped of camera metadata. The filenames retain the original numeric identification. The source HEIC archive remains with the author. These are documentation of physical examples, not an assertion of a controlled printing experiment.
