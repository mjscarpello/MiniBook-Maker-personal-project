# Version 2.1

Recovered source archive: `MiniBookMaker-v2.1.zip`.

The original version 2.1 technical notes describe:
- Cut-stack imposition with up to eight Letter sheets per batch and variable-sized partial batches.
- Adaptive circular-ring punch guides, with measured or estimated stack thickness.
- Separate logical reading order and physical sheet arrangement.
- Calibration and first-batch exports.

Repository preparation changes: documentation reorganized, `.gitignore` added, generated build artifacts excluded, and original source files, tests and build scripts preserved without functional changes. Earlier versions are not included in this archive.
